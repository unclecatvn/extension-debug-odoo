Up and running in a minute

For Chrome, Edge, Brave and other Chromium browsers. It updates itself.

  1. Add Odoo Debug from the Chrome Web Store. On Edge, allow other stores first.
  2. Open any Odoo 18, 19 or 20 page, logged in.
  3. Click the round button at the bottom right, or press Alt+Shift+O.

Debugging Odoo, answered

How do I turn on debug mode (developer mode) in Odoo?

Add ?debug=1 to the URL (?debug=assets for unminified assets), or go to Settings → Activate the developer mode. With Odoo Debug, pick Off / Debug / Assets from the toolbar icon, or press Alt+Shift+D.

Is there a Chrome extension to debug Odoo?

Yes: Odoo Debug, free on the Chrome Web Store, for Chrome, Edge, Brave and other Chromium browsers. It adds a debug panel to every Odoo 18, 19 and 20 page, beyond what developer mode shows.

How do I find which module adds a field or changes a view in Odoo?

Open the Record tab: each field shows its type, value, the module that defines it and what recomputes it. The View tab shows the inherited views that changed the form, and which one made a field read-only or invisible.

How do I debug RPC calls and errors in Odoo?

The RPC tab logs every JSON-RPC call the page makes, with its parameters, result and Python traceback. Edit a call and send it again, or copy it as cURL.

Why can't a user access a record in Odoo?

The Security tab names the access right or record rule that refuses, and the group that would allow it. Try that group in a simulation before granting it.

How do I find slow SQL queries or N+1 problems in Odoo?

The Perf tab profiles a request with Odoo's profiler, flags N+1 queries and points to the line running them.
