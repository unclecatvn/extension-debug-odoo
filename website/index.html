FeaturesTính năng

Developer mode shows what.
Odoo Debug shows why.

Developer mode cho thấy cái gì.
Odoo Debug cho thấy vì sao.

Nine tabs, each answering a question you would otherwise dig out of the source code, the database or the server log. Click a picture for the whole screen.

Chín tab, mỗi tab trả lời một câu hỏi bạn thường phải lục trong source code, database hay log server. Bấm vào ảnh để xem cả màn hình.

Record

What is this field?

Field này là gì?

Its type, value and module, and what recomputes it.

Kiểu, giá trị, module, và field nào khiến nó tính lại.

View

Why is this field read-only?

Vì sao field này chỉ đọc?

The condition, its value right now, and the view that set it.

Điều kiện, giá trị lúc này, và view nào đặt ra.

RPC

What did that call send?

Lời gọi đó gửi gì?

Edit it and send it again right there, or copy it as cURL.

Sửa và gửi lại ngay tại chỗ, hoặc copy thành cURL.

Vì sao Marc không mở được đơn này?

Rule nào chặn, nhóm nào sẽ cho phép, thử trước khi cấp thật.

Chọn nó trên trang: nguồn gốc, và chỗ để sửa.

Mọi module sẽ được cài và tự cài, tính đúng như Odoo.

InstallCài đặt

Up and running in a minute

Chạy được sau một phút

From the Chrome Web Store, in Chrome, Edge, Brave or any Chromium browser. It updates itself. A version not on the store yet: its zip from the Releases, loaded unpacked.

Từ Chrome Web Store, trên Chrome, Edge, Brave hoặc trình duyệt nhân Chromium bất kỳ. Tự cập nhật. Bản chưa lên store: tải zip ở trang Releases rồi nạp dạng giải nén.

  1. 01Open Odoo Debug on the Chrome Web Store.Mở Odoo Debug trên Chrome Web Store.
  2. 02Click Add to Chrome (Edge: allow extensions from other stores first).Bấm Thêm vào Chrome (Edge: cho phép extension từ store khác trước).
  3. 03Open a page of an Odoo 18, 19 or 20 database, logged in, and click the round button at the bottom right, or press Alt+Shift+O.Mở một trang của database Odoo 18, 19 hoặc 20 (đã đăng nhập), bấm nút tròn ở góc dưới bên phải, hoặc nhấn Alt+Shift+O.
  4. 04The toolbar icon: Odoo's debug mode (Off / Debug / Assets), the panel in its own window, language and theme. Alt+Shift+D turns debug mode on or off.Icon trên thanh công cụ: chế độ debug của Odoo (Off / Debug / Assets), panel trong cửa sổ riêng, ngôn ngữ và giao diện. Alt+Shift+D bật / tắt debug mode.
PrivacyQuyền riêng tư

Your data stays in your Odoo

Dữ liệu của bạn nằm yên trong Odoo

Private by design

Riêng tư từ thiết kế

  • Talks only to the Odoo server of the tab you are on, with your own session: no backend, no analytics, no tracking
  • Active on Odoo pages only: elsewhere nothing shows and the toolbar icon is greyed out
  • The session cookie's value is never read, only its flags
  • Odoo data reaches the panel as text only; a module's description shows in a sandboxed frame where nothing runs
  • Source available: read every line on GitHub
  • Chỉ nói chuyện với server Odoo của tab đang mở, bằng chính phiên của bạn: không backend, không analytics, không theo dõi
  • Chỉ hoạt động trên trang Odoo: ở trang khác không hiện gì và icon trên thanh công cụ bị làm mờ
  • Không bao giờ đọc giá trị cookie phiên, chỉ đọc các cờ của nó
  • Dữ liệu Odoo chỉ vào panel dưới dạng chữ; mô tả của module hiện trong một khung sandbox, không chạy được gì
  • Mã nguồn công khai: đọc từng dòng trên GitHub

It writes only when you ask

Chỉ ghi khi bạn yêu cầu

  • Every tab reads; nothing is written behind your back
  • Code: read-only by default; a dry run lists the writes (JavaScript) or rolls them back for real (Python); writes in its writes mode only
  • Security: groups tried are simulated, written only on Apply
  • On your click, as your user: Apps operations, translations edited, Perf's profiles (Odoo deletes them after 30 days)
  • Python runs as a temporary server action, deleted after the run
  • Mọi tab chỉ đọc; không có gì được ghi sau lưng bạn
  • Code: mặc định chỉ đọc; chạy thử thì liệt kê các lệnh ghi (JavaScript) hoặc rollback thật (Python); chỉ ghi ở chế độ ghi
  • Security: nhóm đang thử chỉ được giả lập, chỉ ghi khi bấm Apply
  • Theo cú bấm của bạn, dưới quyền của bạn: thao tác trong Apps, sửa bản dịch, profile của Perf (Odoo tự xoá sau 30 ngày)
  • Python chạy dưới dạng một server action tạm, xoá ngay sau khi chạy
